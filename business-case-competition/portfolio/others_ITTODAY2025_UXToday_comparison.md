# IT Today 2025 UX Today: 3 winning entries compared (+ ITECHNO 🥇 TukaKu)

All four are BINUS teams using the **same UI/UX proposal skeleton**:
1. Abstrak → Latar Belakang → Tujuan & Hasil
2. Design Thinking: Empathize (survey + interview) → Define (persona, empathy, affinity / As-Is-To-Be) → Ideate (solution mapping, acronym, user flow) → Prototype (Crazy 8, wireframe, design system, hi-fi) → Test (heuristic, UT, SEQ, SUS, iteration)
3. Analisis Desain (STP, platform, rich picture, three-tier spec table, navigation map) → Kesimpulan → Pustaka

**Treat this skeleton as table stakes. Winners differentiate on craft, the measured proof and the narrative layer.**

## What the 3 ITTODAY winners collectively teach (vs Wijaya house style)
1. **Measured improvement is the hero proof in every winner.** Run two test rounds and show before → after SUS/SEQ/misclick (only HiBU skipped this). Wijaya already does it; keep it, and add the testimonials and an iteration triplet.
2. **A meaningful local-word acronym is standard** (LENTERA, Jaminan Sehat, SIAP). The edge comes from a metaphor (lantern) or the hidden-letter trick.
3. **Craft signals beyond screens:** WCAG contrast check, a typography token table, a companion device, a demo-video QR, a prototype QR on a full-bleed showcase page.
4. **Each winner has one emotional or brand register applied consistently**: aspirational outdoor (Plogee), calm/feminine (HiBU), clinical urgency (TBCare). Choose the register from the user's emotional state when there's no sponsor brand.
5. **None of the three has business numbers**, so UX Today judges evidently don't require them. Wijaya's strategic layer (TOWS, revenue, impact) is a differentiator, not a requirement, and should stay short.
6. **A fully designed document beats a Docs export** on first impression (Plogee/HiBU vs TBCare), although TBCare still won on logic and proof.
