## Storyline / argument pattern
- **Knowledge–action gap** as the core insight (knowledge 0.62 vs practice 0.45) → two root causes ("concern has no clear action path"; "follow-up is invisible and not sustained") → one journey framework RISE (Recognize, Investigate, Solve, Evaluate) where **each stage = one feature cluster** (AI Scan → contextual education/news/map → photo+GPS report & community events → status tracking & profile).
- Branding: product name ARUN + acronym framework RISE combined into the title "RISE with ARUN"; RISE letters reused as coloured badges on every figure (R/I/S/E pills) to tag screens, root causes and SDG targets.
- Honest-evidence stance: "Pilot dahulu, klaim dampak kemudian" (pilot first, claim impact later) — explicitly states prototype isn't tested yet, personas are secondary-research based, screen data is illustrative, root causes are interpretations. Defines targets instead of inventing results.
- Hook: polluted-river stats + a concrete recent local case (smell and flies entering homes).

## Strengths
- Very tight logic: question → evidence → interpretation → root cause → RISE stage → feature → rationale; RISE letters tag everything, so traceability is visible.
- Strong design-process documentation for a proposal: wireframes, flow with error states, hi-fi states, design system with accessibility contrast, and per-screen design rationale.
- Intellectual honesty (limitations, evidence strength, illustrative data) — reduces judge skepticism.
- Every statistic cited with a URL; recent sources (2024–2026).
- Cohesive teal/water visual identity; premium cover.
- BMC + staged revenue shows sustainability thinking for a social product.

## Weaknesses / what a judge would criticize
- **No primary research** — no survey/interview; personas based on secondary data; no usability testing done yet (only a plan). Against teams like the ITECHNO entry, this lacks validation numbers.
- Some heavy academic Indonesian prose; body in Liberation Serif clashes with the modern sans figures.
- Figures are dense and small at A4 (annotated screen cards, BMC) — hard to read.
- Social-impact metrics (reports resolved, cleanup participation) only as targets; SOM undefined; no cost estimate.
- Dependency on formal partners (government/DLH) for follow-up is acknowledged but not solved — reports "stop at Moderated".
- Differentiation is "combination of existing features" (Litterati, Qlue) — judges may see it as incremental.

## Reusable patterns
- **Acronym journey framework in the title** ("RISE with ARUN") with letter pills reused as tags on every figure.
- **Root-cause tree with separated FAKTA vs INTERPRETASI TIM boxes**, each tagged with the pillar it feeds — shows rigor and honesty.
- **Theory-of-Change table** (before per source → after with product → SDG target).
- **Annotated screen cards**: phone + "what it does" + "what's shown" + "design rationale (alasan desain)".
- **Design system table with contrast ratios and usage** per colour (accessibility points).
- **Flowchart including failure paths** (low AI confidence, failed upload).
- **Design-thinking status table** (per stage: done / outputs / status ✓ or planned) — transparent progress reporting.
- **Exec-summary stat strip** closing with a callout slogan ("Pilot first, claim impact later").
- **Usability targets tied to published benchmarks** (SUS 68, SEQ 5.5, completion 78%) when you can't test yet.
- Branded page frame (top band, wave footer, logo + page no.) gives a plain Writer document a designed feel.
